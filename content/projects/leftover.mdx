Leftover is a mobile application designed to help users reduce food waste by tracking the ingredients they already have and generating recipe ideas from those ingredients. It focuses on practical meal planning by letting users manage pantry and fridge items, receive smart recipe suggestions, and get AI-assisted cooking support for substitutions, meal ideas, and recipe guidance. The app is built as an Expo-based React Native project, with a file-based app structure, reusable UI components, and a lightweight architecture centered around the mobile client and supporting data services.

The codebase is organized around Expo Router screens in the app/ directory, reusable UI components in app/Components/, mock or structured data in data/, and NativeWind styling configured through global.css. It uses React Native as the core framework, Expo modules for image handling, media, storage, and system integration, and Supabase plus AsyncStorage for data persistence and local app state. The architecture is intentionally client-focused and lightweight, with a clear mobile app structure rather than a multi-service backend, making it well-suited for a user-facing recipe and pantry management experience.
