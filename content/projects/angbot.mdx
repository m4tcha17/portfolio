AngBot is a full-stack Discord AI assistant built as a Bun monorepo, combining a Next.js dashboard, Discord bot, Prisma database, and Gemini-powered RAG pipeline. The project allows users to create customizable AI agents, bind them to guilds or channels, and enrich them with uploaded documents so responses are grounded in relevant context rather than generic model output. The architecture is split cleanly across dashboard, bot, database, and shared RAG packages, making it more than a simple chatbo. It functions as a configurable AI platform with real-time management and telemetry.

The system is built around agent configuration, document ingestion, context inheritance, and operational observability. Users can create agents with custom system prompts, model settings, and document knowledge bases, while channel-specific or guild-wide bindings determine how the bot responds in Discord. The project tracks usage through database-backed telemetry, including prompts, responses, tokens, latency, and status logs, which supports both dashboard analytics and debugging. The result is a product-style AI workflow that blends bot interaction, data persistence, LLM generation, and retrieval-based knowledge grounding into one cohesive experience.
