## Problem

CPU scheduling is usually taught through static tables and hand-drawn Gantt charts, which makes it hard for students to see how each algorithm actually allocates time, or to compare algorithms on the same workload.

## Solution

Quanta is an interactive browser-based CPU scheduling simulator. Users input process data, choose a scheduling algorithm, and watch how the CPU allocates time across processes, then compare waiting and turnaround times to see how each algorithm affects system performance.

It supports FCFS, SJF, SRTF, and Round Robin, with results shown as a Gantt chart, per-process metrics, and average system statistics. CSV and JSON import, process validation, and presentation-friendly output make it suited to classroom and project demonstrations. The app is intentionally lightweight and self-contained, with no backend services or database.
