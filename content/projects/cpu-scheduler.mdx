Quanta is an interactive browser-based CPU scheduling simulator designed to help students and developers understand how operating systems make decisions about process execution. It focuses on practical learning by letting users input process data, choose a scheduling algorithm, and visualize how the CPU allocates time across multiple processes. The app helps users compare scheduling behavior, evaluate waiting and turnaround times, and understand how different algorithms affect system performance.

The app supports FCFS, SJF, SRTF, and Round Robin scheduling, allowing users to test each strategy on the same workload and inspect results through a Gantt chart, per-process metrics, and average system statistics. It also includes CSV and JSON import support, process validation, and presentation-friendly output for classroom or project demonstrations. The architecture is intentionally lightweight and self-contained, with no backend services or database, making it well-suited for a focused interactive learning experience in operating systems.
